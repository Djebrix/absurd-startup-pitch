One sentence, 200 characters at most, pitching a bizarre startup idea that sounds absurd until you realise it would actually sell.

Entry for [Ridiculous at First Glance, Real by the Second](https://make.fun/bounty/u-po-pu-ridiculous-at-first-glance-real-by-the-second-9a97d12a) on make.fun.

## Run

```sh
python3 main.py
```

Writes the pitch sentence to `$ENTRY_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`). Stdlib only, no network, deterministic.
